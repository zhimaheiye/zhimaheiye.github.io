本地抓取输入法输出

需求描述：

我最近有个需求是，我每天会输出很多内容，但这些输出的内容大部分都浪费掉了。如果能让AI学习我输出的这些内容里的东西，把它整理成一个知识库，之后就能更好的跟我交流。cherry Studio里的全局记忆是很符合我这个需求的，但是它最近坏了，我暂时弄不明白是什么原因。简单来说就是想省掉“把自己的提示词复制一遍，粘贴到某个ai窗口里让它输出总结”的这个过程。于是想能不能从输入法下手

可能的解决方案以及否决的原因：

方案一：Obsidian + AI 插件

  • 尝试工具：Smart Connections。
  • 否决原因：
    1. 测试相关性搜索效果一般。
    2. 笔记都是有意识整理好的，我更希望能够进行全部的、没有筛选性的抓取

方案二：Quicker + 本地 API

  • 方案逻辑：在任何窗口选中文本 -> 触发 Quicker 动作 -> 发送给 Ollama 提取 -> 存入本地文件。
  • 优点：灵活，覆盖所有软件，保留了“主动选择”的权利
  • 否决原因：
    不够无感。还是需要“手动操作选择”，我不喜欢这种每次都要打断思路去操作一下的感觉

3. 最终选择：Rime 输入法 + 挂钩日志

核心逻辑：利用 Rime 的 Lua 脚本功能，在输入的同时静默记录日志。

隐私安全：
虽然是本地输入，但建议在输入密码等极度隐私的内容时，切换回 Windows 原生输入法。

4. 语音模块：CapsWriter-Offline

为了解决“不想打字”时的输入问题，引入了本地语音识别。

  • 工具介绍：GitHub 开源工具，利用 Whisper 模型本地识别。
  • 操作流程：
    1. 按住 CapsLock 说话。
    2. 松开，几百毫秒内转文字。
    3. 关键点：通过模拟键盘输入上屏，所以能被 Rime 的 Lua 脚本完美抓取。

切换默认输入法：

适用于 Windows 11

  1. 按下 Win + I 打开 设置。

  2. 点击左侧的 “时间和语言” (Time & language)。

  3. 点击右侧的 “输入” (Typing)。

  4. 找到并点击 “高级键盘设置” (Advanced keyboard settings)。

  5. 在第一项 “替代默认输入法” (Override for default input method) 的下拉菜单中：

    • 默认是“使用语言列表（推荐）”。

    • 请把它改成：中文(简体) - 小狼毫。
